# Velour salon template and visible account access

The supplied Archive 2.zip contains ten design-reference screenshots. No source
instructions were embedded. The additional original `salon-luxe` template uses
warm cream, burgundy pill navigation, a full-bleed portrait, service cards, a
three-person artist section, split client stories and an interior booking panel.
No reference screenshots, Wix branding or client identities were used as assets.

Public preview: `/templates/salon-luxe`. Main and Business use the same registry,
renderer and local images, including a real rendered catalog thumbnail and an
original SVG fallback. Existing template IDs and customer drafts are preserved.
The new design remains editable through the existing beauty document and fields.
Home, story, services, individual service pages, gallery, booking and contact
reuse the current routes, request actions and authorization. Demonstration names,
prices and reviews are labeled; preview forms do not send real requests.

All template headers now have a visible 44px account icon outside the collapsible
menu, including blank, landing and beauty templates. Its accessible name is
“Sign in to JKTL Business”. Public previews carry their template ID to Business
login and leave the preview frame; published sites link to Business login.
This reuses the existing JKTL account system, not a new client membership area.

Verification includes all-template rendered sign-in links, document round trips,
independent new drafts, service routes, representative desktop/320/390px layouts,
public previews, new-tab gallery behavior, builds and focused lint. No live
customer enquiry, notification or email is sent by these checks.
No migration, new dependency, environment variable or authentication change.
