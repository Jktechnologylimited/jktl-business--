# Lumi Atelier

The 16.8-second uploaded screen recording is a visual reference for a salon, not implementation instructions. Added `lumi-atelier` to Main and Business: a nine-page editable salon website with a three-image editorial hero and floating headline panel, service index, three individual service pages, about, gallery, consultation and contact pages.

Reuse the existing beauty editor, owner-supplied artist profiles and contact details, real enquiry handlers, publication actions, canonical metadata and sitemap helpers. Public previews need no signup; sign-in and selection retain the template ID. Photography uses existing bundled African portraits and the existing interior asset. No new database schema, fake appointment confirmation or checkout is introduced.

Desktop and phone layouts, preview navigation and form boundaries use the existing components. Production builds skip npm lifecycle hooks to avoid running database migrations. Keep changes local until deployment is authorized.
