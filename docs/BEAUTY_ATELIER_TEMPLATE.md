# Beauty atelier template and catalog motion

The supplied archive contains eight reference screenshots, not source code or instructions.
Rouge Bloom Studio is an additional original, editable template inspired by the red/ivory
serif typography, split hero, service rows, photographic reviews and artist section.
No Wix branding, screenshots, customer identities or testimonials are reused as site assets.

- ID: `beauty-atelier`; public preview: `/templates/beauty-atelier`.
- Available in Main and Business using the existing template registry and editor.
- Home, story, services, individual service pages, gallery, booking and contact reuse
  the existing beauty website routes, request actions and tenant authorization.
- New drafts preserve the atelier style through existing document parsing. Existing
  salon drafts and customer sites keep their current design.
- Names, prices and testimonial are editable demonstration content. Studio details
  are blank until the customer supplies them. Preview forms do not submit requests.
- Images are local copies of Unsplash photography; the gallery thumbnail is a real
  rendered screenshot. A local original SVG supplies the usual fallback.
- Gallery thumbnails, View buttons and Info → View open public previews in a new
  tab with `noopener noreferrer`. Edit/Select retain the existing login/editor flow.
- Framer Motion animates card hover and return transitions; reduced-motion
  preferences disable those effects. Content remains rendered on the server.

Verification: document parsing/rendering regressions, gallery filtering/new-tab
browser checks, public page responses, phone overflow and visible booking controls,
production builds and focused lint. No live customer requests or emails were sent.
No migration, new dependency, credential or authentication change is required.
