# JKTL Business

A mobile-first, multi-tenant business platform for Nigerian SMEs. First
vertical: hair salons.

See **CHECKPOINT.md** for what's built in this pass, what was decided along
the way, and what's next.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 — you'll land on `/login`. Use the "Open salon
demo" button, or sign in with `ada@glamhair.jktl.com.ng` / `glamhair`.

This is Phase 1: everything runs on mock data in `src/lib/mock/`, held in a
client-side store (`src/lib/store.ts`). No database, auth provider, or email
service is connected yet — that's Phase 2, and it hasn't started.

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Zustand

## Regenerating icons

`public/icon-*.png` were generated by `scripts/make-icons.py` (Pillow). It
needs a bold sans-serif TTF file of your own — none is bundled — see the
comment at the top of the script.
